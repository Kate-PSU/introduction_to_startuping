# Market Scope Lab

Интерактивная лаборатория расчёта TAM, SAM и SOM для курса «Лингвистический стартап».

## Возможности

- обучающие задания по различению TAM, SAM и SOM;
- разбор типичных ошибок оценки рынка;
- выбор модели B2C, B2B, B2G или B2B2C;
- навигатор по доступным российским источникам;
- паспорт исходных данных с разделением фактов и допущений;
- top-down и bottom-up калькуляторы;
- расчёт SOM через охват, конверсию и ресурсную ёмкость команды;
- сравнение методов, сценарный анализ и итоговый паспорт рынка;
- автоматическое сохранение в браузере, копирование и печать в PDF.

## Публикация

Загрузите папку `market-scope-lab` в корень репозитория GitHub Pages. Сборка и внешние библиотеки не требуются.
