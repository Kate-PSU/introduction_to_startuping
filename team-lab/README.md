# Анатомия команды стартапа

Интерактивная групповая лаборатория для раздела «Формирование команды» курса «Лингвистический стартап».

## Этапы

1. Исследование реальной команды лингвистического стартапа с двумя источниками.
2. Сбор собственной команды при бюджете 12 жетонов.
3. Случайная кризисная карточка и адаптация команды.
4. Автоматически сформированный паспорт команды для короткой защиты.

Ответы автоматически сохраняются в браузере. Персональные данные не собираются и никуда не отправляются.

## Публикация

Загрузите папку `team-lab` целиком в корень уже существующего репозитория GitHub Pages. После публикации приложение будет доступно по адресу:
