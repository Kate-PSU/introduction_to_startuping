# Стартап-миссия

Интерактивная игра для закрепления первой лекции курса «Лингвистический стартап»: определение стартапа, ключевые признаки и семь типов стартапов.

## Что включено

- пять игровых миссий;
- выбор признаков;
- распределение карточек перетаскиванием;
- аудиоподсказки через синтез речи браузера;
- интерактивный конструктор стратегии;
- ситуационный финальный раунд;
- итоговый результат из 100 очков;
- адаптация для телефона, ноутбука и проектора.

Игра не использует внешние библиотеки, сервер или регистрацию.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория `index.html`, `styles.css`, `app.js`, `.nojekyll` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
6. Через несколько минут GitHub покажет ссылку на игру.

## Проверка локально

Откройте `index.html` в браузере. Для полноценного тестирования буфера обмена запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000/`.
