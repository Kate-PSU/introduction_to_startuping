# Idea Lab

Интерактивный практикум к разделу «Формирование и разработка идеи» курса «Лингвистический стартап».

## Что делает приложение

- переводит наблюдаемую проблему в формулировку Point of View;
- помогает создать вопрос «Как мы можем…?»;
- проводит по семи направлениям SCAMPER;
- позволяет сравнить варианты по ценности, реализуемости и отличию;
- собирает ценностное предложение и короткий питч;
- формирует SMART-цель первого эксперимента;
- сохраняет черновик в браузере;
- экспортирует результат в Markdown и в PDF через печать.

## Размещение на GitHub Pages

1. Загрузите папку `idea-lab` целиком в корень репозитория `introduction_to_startuping`.
2. Убедитесь, что в папке находятся `index.html`, `styles.css` и `app.js`.
3. После публикации приложение будет доступно по адресу:
   `https://kate-psu.github.io/introduction_to_startuping/idea-lab/`

Приложение не требует сервера, регистрации или внешних библиотек.
