# Customer Lens Lab

Интерактивная лаборатория для главы «Сегменты рынка и портрет клиента» курса «Лингвистический стартап».

## Публикация на GitHub Pages

Загрузите папку `segment-lab` в корень репозитория, где уже включён GitHub Pages. Приложение будет доступно по адресу:

`https://<username>.github.io/<repository>/segment-lab/`

Приложение не требует сборки и внешних библиотек. Ответы сохраняются в `localStorage` текущего браузера.
