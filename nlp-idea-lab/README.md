# NLP Idea Lab

Интерактивный конструктор первой проектной гипотезы для курса «Лингвистический стартап».

## Возможности

- выбор проблемного поля и целевой аудитории;
- формулировка пользовательской проблемы;
- выбор до трёх NLP-технологий;
- генерация трёх вариантов концепции;
- проверка реалистичности идеи;
- итоговый паспорт проекта, копирование и печать в PDF;
- автоматическое сохранение данных в браузере.

## Размещение на GitHub Pages

Загрузите всю папку `nlp-idea-lab` в корень репозитория. После публикации адрес будет иметь вид:

`https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/nlp-idea-lab/`

Приложение не требует сборки, сервера, регистрации или внешних библиотек.
